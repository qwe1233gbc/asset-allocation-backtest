# 资产配置回测工具

标普500 · 纳斯达克100 · 中证红利低波 (分红再投资) — 交互式回测与资产配置优化

## 在线使用

直接在浏览器中打开 `index.html`，或通过任意静态文件服务器托管。

```bash
python -m http.server 8765
# 访问 http://localhost:8765
```

## 功能

### 概览
- **累计收益对比**: 对数尺度展示当前配置 vs 单一资产 vs 定投的长期收益
- **定投模拟 (DCA)**: 按月定额投入，对比一次性投入 vs 定投的差异
- **日历年收益表**: 每年一行的收益矩阵，颜色标注正负，直观对比熊市表现

### 收益分析
- **滚动年化收益**: 5年期和10年期滚动窗口，覆盖多轮牛熊
- **有效前沿图**: 231个预计算组合的收益/风险散点，标注当前配置位置

### 风险分析
- **回撤曲线**: 任意时间点的回撤百分比，叠加单一资产回撤对比

### 策略对比
- **再平衡策略对比**: 模拟"每年再平衡"、"偏离5%触发"、"不调仓"三种策略
- **策略详细对比表**: 年化收益、波动率、最大回撤、夏普比率、总收益

### 交互
- **三滑块联动**: 自动锁定总和100%，比例再分配
- **快速选择**: 6种预设配置一键切换 (60/30/10, 40/40/20, 0/65/35等)
- **暗色模式**: 一键切换，偏好自动保存

## 数据

- **时间范围**: 2005-02 至 2026-04 (14.2年, 170个月)
- **数据来源**: [akshare](https://github.com/akfamily/akshare) (index_us_stock_sina / index_zh_a_hist)
- **标普500**: S&P 500 (.INX)
- **纳斯达克100**: 使用纳斯达克综合指数 (.IXIC) 作为代理 (相关系数 >0.95)
- **中证红利低波**: 中证红利低波指数 (000015)
- **分红处理**: 每月总收益 = 价格收益 + 估算月度股息 (分红再投资)
  - SP500 年股息率: 1.8%
  - 纳斯达克 年股息率: 0.7%
  - 红利低波 年股息率: 3.8%

## 使用方法

1. 打开 `index.html`
2. 拖动滑块调整标普500、纳斯达克100、红利低波的配置比例
3. 观察各项指标实时更新
4. 查看滚动年化收益图表，了解不同入市时机的影响
5. 在有效前沿图上找到最优风险收益比

## 技术栈

- 纯静态 HTML/CSS/JS，无需构建工具
- [Chart.js](https://www.chartjs.org/) 4.4.7 图表库 (CDN)
- 数据预计算 (231个组合，5%/10年期滚动窗口)
